# Свадебное приглашение — демонстрационная копия

Путь: `/demo/wedding/` с префиксом текущего GitHub Pages. Самостоятельный статический документ находится в `public/demo/wedding/`, автоматически копируется существующей Vite-сборкой. Его стили и скрипт не загружаются в приложение портфолио. Исходный frontend wedding использован только для чтения и копирования визуальной части; Git, Worker, настройки и административные инструменты не переносились.

Композиция, цвета, шрифты, SVG-сердца, нитки, конверт, снег, бегущая строка и анимация тайминга сохранены из источника. Шрифты размещены локально вместе с лицензиями. Фотографии пары и реальной площадки не включены. Имена, дата, время, площадка, адрес-заглушка и подпись заданы вымышленными значениями в HTML и локальном скрипте. Локация нейтральная; публичный авторский блок сохранён.

Предоставленный PNG хранится без изменений в `source-assets/wedding-demo/`. `node scripts/prepare-wedding-demo-assets.mjs` создаёт прозрачную WebP-копию до 1000 px без обрезки. Обложка и крупное превью проекта сняты с готовой обезличенной страницы, включая новую композицию, имена и дату. Они находятся в `public/assets/experiments/projects/`.

Единственная запись проекта находится в `src/data/experiments.json`, массив `digitalProjects`. Компонент `DigitalProjects.tsx` выводится внутри существующего единственного окна рабочего стола. Ссылка демоверсии учитывает базовый путь, открывается в новой вкладке с `noopener noreferrer`. На самой демоверсии есть обратная ссылка в «Эксперименты».

Анкета проверяет поля локально, сохраняет значения только в DOM открытого документа, очищается при загрузке/возвращении страницы. Рабочие интеграционные модули и их конфигурация исключены целиком. Нет чтения параметров URL, сетевой логики, хранилищ, аналитики, гостевых идентификаторов или скрытого рабочего режима. CSP дополнительно запрещает соединения и отправку HTML-форм. Выбор парковки демонстрационный; никаких квот или бронирования нет.

`tests/wedding-demo.spec.ts` проверяет 1440/768/390 px: компоненты приглашения, все состояния формы и ошибок, очистку после перезагрузки, отсутствие соединений/хранилищ/утечек, игнорирование параметров URL, карточку, восстановление окна, новую вкладку и обратный переход. Неожиданные сетевые запросы блокируются до отправки; настоящие серверы анкет не используются. Отдельная проверка анализирует файлы итоговой сборки и допустимый набор ресурсов.
