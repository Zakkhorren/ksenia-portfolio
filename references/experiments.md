# Материалы «Экспериментов»

Маршрут: `/work/experiments/`. Интерфейс — `src/components/ExperimentDesktop.tsx`, стили ограничены рабочим столом в `src/styles/experiments.css`.

Данные находятся в `src/data/experiments.json`. Для новой серии добавьте объект в `series`: стабильный `id`, `title`, `cover` (идентификатор фотографии), упорядоченный `images`. При необходимости можно хранить `year` и `description`; интерфейс их не требует. Изображение содержит `id`, короткий `alt`, `thumbnail`, `src`, `width`, `height`. Пути ресурсов задаются относительно `public/assets`. Не меняйте идентификаторы уже опубликованных работ.

Анимации добавляются в `animations`: `id`, `title`, `cover` (статичное превью для сетки и reduced motion), `src` (исходный GIF), `width`, `height`, `frames`. Компонент автоматически строит папку и переключение по списку данных. Новые альбомы также автоматически появляются в списке серий.

Оригиналы этой поставки побайтно сохранены в `source-assets/experiments`, вне `public` и `dist`. `scripts/prepare-experiments.mjs` воспроизводит текущую подборку из этих оригиналов (`node scripts/prepare-experiments.mjs`), либо принимает путь к исходной поставке первым аргументом. В нём зафиксирован визуально проверенный порядок текущей серии; для другой поставки подготовьте производные и добавьте запись в JSON. Обычная сборка не обрабатывает и не требует оригиналов.

Фотографии: 20 уникальных исходников (№1–9 и №11–21), обложка и заключительный кадр №12. Миниатюры WebP до 720 px. Просмотр: исходные уже оптимизированные JPEG (до 1280 px), в которых отсутствуют EXIF/XMP/IPTC/GPS и профили. Они скопированы побайтно вместо повторного сжатия в более тяжёлый WebP; обработка и качество не менялись. Скрипт удаляет метаданные и ограничивает размер до 2200 px для будущих исходников, если это потребуется. Только вписывание, без обрезки. GIF копируются без изменений: утренний — 4 кадра, работающий — 2, спящий — 6, по 250 мс. Статичные превью берутся из первого кадра. Caveat 400 — официальный вариативный файл Google Fonts; лицензия рядом с файлом шрифта.

Проверки: `tests/experiments.spec.ts` — четыре ширины, все материалы, порядок, возврат/прокрутка, сворачивание/восстановление, размеры/границы окна, клавиатура, reduced motion, доступ через существующую навигацию и ошибки ресурсов/консоли. Публикация остаётся через существующий `.github/workflows/pages.yml` при push в `main`.
